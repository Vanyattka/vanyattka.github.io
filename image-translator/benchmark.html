How we measure Image Translator

Every version is tested before release. We measure what you actually read — the translation of the picture — not only the recognized text. All numbers below come from one run on 2026-10-18: MacBook Air M3, Chrome 155.0.8059.82, recognition on the graphics card (WebGPU), build 0.1.0.

Test sets

  • Synthetic pictures from FLORES-200. FLORES-200 is the same set of sentences translated by people into 200 languages (Meta, CC BY-SA 4.0). We render them in Chrome, with system fonts, as 8 kinds of pictures — 27 languages × 8 kinds × 3 samples = 648 images. The sentences and layouts are the same in every language, so languages can be compared with each other. Hebrew and Bengali are included on purpose: the extension can't read them yet, and the test shows it; they are not in the averages.
  • Real scans from XFUND. 70 scanned forms — 10 each in Chinese, Japanese, German, French, Spanish, Italian and Portuguese — with handwritten fields, tables and stamps.

Measures

  • Translation chrF++ — the translation of the picture against the human translation from FLORES-200: character n-grams up to 6 and word pairs, β = 2, case-insensitive, checked against sacrebleu. The main number.
  • Ceiling — the same Chrome translator on the error-free text of the picture. Ceiling minus translation (loss) is everything that recognition and layout cost; the ceiling itself is a property of Chrome's translator.
  • CER — character error rate of recognition against the text on the picture (for Chinese, Japanese and Thai without spaces).
  • Real scans have no human translation, so there we measure how much of the translation is kept (chrF++ against the translation of the error-free text) and words as a bag against the dataset's annotation: F1, recall (share of words found) and precision.
  • Time — median per picture, from the image bytes to the translation: decoding, text detection, script probe (in automatic mode), line recognition, translation.

Known weak spots

  • Vietnamese — the recognizer's alphabet lacks some tone-marked letters, so translation loses 18.1 points.
  • Arabic loses 12.7 points; Telugu 5.9, Thai 4.7, Marathi 4.2, Korean 3.8.
  • Hebrew and Bengali can't be read yet; Kannada is not in the test and can't be read either.
  • Handwriting is recognized only partially.
