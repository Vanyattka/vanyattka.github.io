Privacy policy

Last updated: 2026-10-18

Image Translator does not collect, store, sell or share any personal data.

Images are processed entirely on the user's computer. Text recognition is done by models that ship inside the extension (ONNX Runtime on the graphics card or the processor). Translation is done by Chrome's built-in on-device translator. Images, recognized text and translations are never sent anywhere and are not saved; only the user's settings stay in the extension's local storage on the user's computer.

The extension makes no network requests of its own. When the user asks it to translate an image on a web page, the image is loaded from its own address, exactly as the page loads it. The translation packs for Chrome's built-in translator are downloaded by Chrome itself when the user clicks the download button; they contain no user data.

The extension uses no analytics, shows no ads, has no server and shares no data with third parties.
